Offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies, with cited guides, a saved checklist, filters, spoiler mode and a platinum roadmap. Every trophy carries its official name, description and grade, a guide in our own words with its sources beside it, and the one potentially missable trophy is flagged — no online trophies exist, and five methods were still unconfirmed at launch and are marked as such rather than guessed.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser. The guide works with the network off: everything it loads is a file under `app/`, and your progress is stored only in your browser (localStorage), with export and import.
