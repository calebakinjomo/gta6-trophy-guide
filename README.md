Leonida Legends is the complete guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, own-words guides with cited sources, a saved checklist with export and import, kind and grade filters, a spoiler setting, and a step-by-step roadmap to the platinum. It is a static offline web app — no network needed.

## Run it

```sh
node --experimental-strip-types main.ts
```

Then open `app/index.html` in a desktop browser, or serve the `app/` folder with any static server. To build the submission dossier locally: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
